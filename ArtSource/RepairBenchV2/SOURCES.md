# Sources

Wear, grain and rubber masks in `Textures/` are derived (downsampled, desaturated, recoloured) from these ambientCG
materials, all CC0 1.0 Universal (public domain), downloaded 2026-10-20 from https://ambientcg.com:
PaintedMetal004, PaintedMetal002, Metal032, Rubber004, Plastic010, Chipboard004.
Geometry, palette, mat print and pixel text are original to this project (`build_repair_bench_v2.py`).
