# 真人鼠标操作检查 · 清单

自动测试已用 Input System 虚拟鼠标走完“悬停 → HUD → 点击 → 占位动作”的链路，但那不是真人操作。
下面这份清单需要真人在编辑器里操作一遍，大约 5 分钟。

## 准备

1. 用 Unity 6000.0.84f1 打开 worktree `BorderRepairStation_workbench`，分支 `art/workbench-area`。
2. 打开 `Assets/WorkbenchArea/Scenes/WorkbenchArea_Test.unity`，Game 视图设为 1920×1080（或 16:9），然后进入 Play。
3. 场景里的 `MouseSessionLog` 会记录每次悬停变化和点击，包括点空、点到被挡住的对象。退出 Play 时写入 `Logs/wb/mouse_session_<时间>.txt`。检查完把这个文件发回即可。

## 步骤与预期

| # | 操作 | 预期（HUD 左上） | 实际 / 备注 |
|---|---|---|---|
| 1 | 游戏镜头下，鼠标慢慢扫过诊断仪屏幕、三个旋钮、电源拨杆 | 依次显示对应名字；读数屏幕清楚，没被杂物挡住 | |
| 2 | 指向螺钉托盘、旧件托盘，各点一次，再各点一次 | 托盘抬起、拉到台沿外；再点一次原路放回（【占位】） | |
| 3 | 指向工具箱上层 | 提示“下面的 Toolbox_Tier1 被它挡住：点击工具箱上层或按 U 先移开它” | |
| 4 | 找一找能不能指到工具箱下层 | 如果指到，显示“被 Toolbox_Tier2 挡住：先移开上层才能取用”；点击不执行动作 | |
| 5 | 点工具箱上层 | 上层抬起；此时指向下层能正常选中，不再提示被挡住 | |
| 6 | 按 Tab 切到近距维修镜头 | 能同时看见：义肢占位件、两个托盘、左侧探针；4 颗发黑螺钉在盖板上清楚可辨 | |
| 7 | 逐个指向 4 颗螺钉、盖板、接口、红色故障灯 | 每个都能单独选中，名字前有“【占位】” | |
| 8 | 指向盖板旁边露出的检修口 | 显示“被盖板挡住：先拆下盖板才能检查” | |
| 9 | 按 D | 螺钉逐颗进螺钉托盘，盖板落进 COVER 停放框，四周留有余量（【占位】） | |
| 10 | 再指向检修口，然后再按 D | 检修口可以选中；按 D 后全部装回原位 | |
| 11 | 随意点台面上的杂物、墙面 | 杂物和墙面不可选中；不应出现看着像能点、点了却毫无反应又没有提示的东西 | |

## 需要记下的主观感受

- 在游戏镜头下，哪些东西让你以为能点，实际点不到？
- 悬停反馈的速度和准确度怎么样？小件（螺钉、旋钮、故障灯）是否容易点偏？
- 暖光焦点是否把视线引到操作区？画面暗处是否看不清你需要的东西？
