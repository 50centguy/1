## 0. 第二轮：美术复核与修改

复核对象：实际 Unity 截图 `U06_game_camera.png`、`U03_player_closeup.png`，对照 V3 的 `02-prosthetic-repair-closeup.png`。

### 复核发现（改前）

1. **游戏镜头过于空。**
   - 台面后沿、墙面、收纳区只有零星物件，台下是一大块空黑。
   - 看不到新旧混用的义体外壳、补过的线、半开的零件盒、积压的工单。
2. **光照被均匀的暗绿吞没。**
   - 平光绿灰环境光加冷色顶灯，把整幅画面压成一片。
   - 工作灯只在垫子上留下一小块暖色，算不上焦点。
   - 绿墙、绿洞洞板、绿抽屉之间几乎没有明度和色相差。
3. **占位件只是一根灰蓝长条**，没有手腕和手的轮廓；占位标签贴在背面，看不到。
4. **近距镜头只框住义肢**，看不到工具和零件托盘在哪。
5. **盖板停放框与盖板等长**，余量为 0。
6. **工具箱下层被上层盖住**，游戏镜头下点不到，但也没有任何提示。

### 与 V3 参考仍有的差距（如实列出）

- **密度。** 参考是 AI 生成的近景，杂物密度远高于这里。这里为了保证中央拆装区、双手路径、托盘和盖板路径、诊断读数始终清楚，杂物只放在边缘和墙面，这是有意的取舍。

### Draw Call：独立构建实测与来源拆解

测量条件：Release 构建，1920×1080，D3D11，RTX 3070，质量档 PC。全文见 `Reports/Unity/drawcall_breakdown_standalone.txt`。

| 情况 | Draw calls | Batches | SetPass | 渲染三角面 | 帧时间中位 |
|---|---|---|---|---|---|
| 游戏镜头 · 完整 | 270 | 192 | 39 | 22,353 | 1.30 ms |
| 近距镜头 · 完整 | 228 | 178 | 37 | 18,481 | 1.35 ms |

游戏镜头的 270 次，按逐项关闭的差值拆解：

| 来源 | Draw calls | 说明 |
|---|---|---|
| SSAO 渲染特性 | **100** | 项目 PC 渲染器全局开着 SSAO，它的深度法线预通道把所有可见几何再画一遍，外加 AO 通道。不是本场景加的 |
| 几何主通道 | **97** | 每个可见 Renderer（98 个）约 1 次；其中杂物 31、占位件 12、诊断仪 11、台体 9、工具箱 7 |
| 工作灯阴影图 | **43** | 58 个阴影投射体 |
| 后处理 | 17 | 色调映射、对比、暗角 |
| IMGUI 测试 HUD | 9 | 只在测试场景里有 |
| 管线固定开销 | 4 | |

第一轮报告里的 199 次是编辑器里测的（含编辑器开销），而且当时没有后处理、物体也更少，不能直接与 270 次比较。

结论：三角面不是来源，减面几乎没有用。按收益排序的建议如下，都还没有执行，等确认：

1. **SSAO 是项目级决定。** 低面数复古风格是否需要 SSAO？关掉它最多省 100 次，但会影响所有场景，要在项目层面决定。
2. **阴影投射体。** 工作灯光锥外的墙面、货架、洞洞板杂物关掉 Cast Shadows，预计能从 43 次里省一大半，画面基本不变。
3. **不交互的杂物按材质合并。** 31 次能降到约 10 次，代价是失去单件可编辑性（Blender 源文件不受影响）。
4. **HUD** 是测试用的，正式 UI 会换掉。

Unity 编辑器内（Game 视图 1471×886）同场景：游戏镜头 269 次，去杂物后 204 次，近距镜头 216 次；帧时间约 2 ms。
