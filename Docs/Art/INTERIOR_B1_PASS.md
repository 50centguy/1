# B1 诊所内部：分区、墙面、灯、生活痕迹

第 1–10 节是第一轮，第 11 节是第二轮（质感和打光）。两者有冲突的，以第 11 节为准。

这一轮整理的是 `Assets/RepairProps/Scenes/Temp_Berth04District.unity`（试摆场景）里的 B1 诊所内部。正式场景 `RepairProps_Clinic.unity` 没有动，按 `ART_STYLE_GUIDE_v2.md` 的规矩，布局改动先在试摆场景试。确认后再搬过去。

工具：`Assets/RepairProps/Editor/ExteriorDistrictPass.Interior.cs`，和外景用同一个 partial class 与同一套工具函数。

- 菜单：
  - `Border Repair/Interior/Apply interior pass`
  - `Border Repair/Interior/Inspect B1 clinic`
  - `Border Repair/Interior/Render interior shots`
- 批处理：`-executeMethod BorderRepair.RepairProps.EditorTools.ExteriorDistrictPass.{ApplyInterior|InspectInterior|InteriorShots}`。
- Inspect 可以加环境变量 `INTERIOR_PROBE="x0 y0 z0 x1 y1 z1;..."`，列出与这些盒子相交的全部渲染器。
- Shots 可以加 `INTERIOR_VIEWS="名字|眼 x y z|看 x y z;..."`，多出几张图。
- 可以重复运行，两次运行后场景里的名字、变换、激活状态完全一致：
  - 新增的东西都放在根节点 `09 Interior pass - B1 clinic` 下，每次删掉重建。
  - 交接物体（隔墙、货架、手术台、灯）的移动和换材质都写绝对值。
  - 项目预制体本身不改，只改这个场景里的实例。
- 素材在 `Assets/RepairProps/Scenes/Temp_InteriorPass/`：
  - `Textures/` 下：
    - 四套实拍表面（`srf_int_*`，Poly Haven CC0，见第 8 节）；
    - 告示板、钟面、挂历、员工通道牌、保养海报、处置区牌，由 Python/PIL 生成。
  - `DepthText.shader`：做深度测试的 3D 文字。
  - `Room reflection.exr`：房间反射探针，Apply 时烘焙。
  - `Materials/`、`Meshes/`：Apply 生成。
- 墙面用外景的 `Surface.shader`，新增 `_Kind = 5`（室内墙）：上半是脏混凝土，下面是 1.15 m 高的烟绿色旧油漆墙裙，交界有一条暗线，墙根积灰。

## 1. 原来的问题（实测）

- 货架横在后墙前，穿进隔墙 0.3 m；手术龙门环贴着隔墙和右墙。
- 客人一进门就能走到工作台和手术台，等候区与工坊之间没有任何分隔。
- 右前方 (x 0.3–3.5, z 0.2–3.5) 一片空地。
- 墙和天花是铆接钢板，与风格指南的“混凝土 + 烟绿旧漆”不符。前墙的室内一侧露着外景混凝土，街面首层侧楼的盒子还穿进室内 12 cm。
- 地面其实看不见：港口水面是一整块盒子（108 × 0.34 × 51，顶面 y 0.05），比地坪（y 0）高 5 cm，房间像泡在黑水里。
- 天花上有一块冷蓝光斑（Cool room bounce），灯具是发白的方盒子。
- 3D 文字都用 Unity 字体材质，会画穿墙：楼梯口的 “B1 REPAIR” 反着透进地下室，“收件”从柜台背面也看得到。
- UNIT 07 的维护角套件（DockCornerV2）在交接里是关掉的，半截插在门口墙里。

- 柜台后是工坊：工作台、UNIT 07 维护位、货架。
- 手术区在右后，有隔墙和帘子。

## 4. 灯

- 两根日光灯管替代原来的方盒子：
  - 工坊：暖白，带软阴影，是房间的主光。
  - 等候区：中性白。
- 门内挂一只带铁丝罩的裸灯泡：暖色，照门口地垫和托盘前站的人。
- 交接的灯：
  - Cool room bounce：冷蓝改成暖灰的低位补光（i 0.9）。天花上的蓝斑没了。
  - Dim alcove fill：改中性白（风格指南：手术位是中性白）。
  - Low dock fill：调弱到 1.8。
- 原壳体的两个灯具盒改成灯管材质。
- 房间加一个盒投影反射探针，Apply 时烘焙。烘焙时只临时把房间里的物体标成反射静态，之后改回原值。钢件、湿地垫不再反射外面的雪夜天空：之前推车和栏杆发白，就是这个原因。

## 11. 第二轮：质感和打光

反馈是“比之前差了点质感，打光也一般”。对比后找到的原因：

- 原来的铆接钢板墙和泡在水里的黑地面有高光、有反射，看起来是“材质”。第一轮换成了全哑光的混凝土和地面，颜色又接近，整屋发闷。
- 墙、地、天花用的外景 `Surface.shader` 是 Blinn-Phong 光照，完全不吃反射探针；它也没有 DepthNormals pass，项目的 SSAO 看不到这些面，墙角、地脚没有遮蔽。
- 两根灯管是 150° 的大泛光，整屋一样亮，没有光池和衰减。
- 新加的道具是直角方块加纯色，边缘不吃光。
- 截图也不对：试摆场景的相机没开后处理，用的是默认渲染器，跟 `RepairProps_Clinic` 里真正的相机不是一回事。

### 截图管线

`Render interior shots` 现在按诊所相机的设置出图，只在出图时临时加，不存进场景：

- 渲染器 1（RetroRenderer：柔光扩散 + SSAO），并挂上 `RetroClinicCamera`（扩散 0.16，半径 1.3 px）；
- 开后处理，Volume 层为 Default + 30；
- 一个临时全局 Volume，用诊所共享的 `WB_PostProfile`：Neutral 色调映射、曝光 +0.25、对比 +12、饱和 +4、暗角 0.22。

设 `INTERIOR_LOOK=raw` 可以回到原来的裸渲染。“之前”的对比图也按同一套管线重渲了，两边条件一致。

### 表面（`Surface.shader` kind 5）

- kind 5 改用 PBR 光照（`UniversalFragmentPBR`），能吃房间的盒投影反射探针。外景的 kind 0–4 仍是 Blinn-Phong，不变。
- 加了 DepthNormals pass，所有用这个 shader 的面都进 SSAO，外景也一样。外景截图对比第三轮，平均像素差约 1/255，只是台阶、墙角多了一点遮蔽。
- 新参数：
  - `_GlossVar`：光泽跟着贴图走，深色处更潮、更亮。
  - `_Peel`：墙裙油漆按贴图明暗剥落，露出混凝土，剥落边缘一圈发暗，靠近墙裙顶线剥得多。
  - `_Puddle`：地面零星的潮斑。
  - `_WetZone`：一块指定的湿区，用在门口。
  - 墙根除了积灰，也更潮、更亮。

| 部位 | 现在 |
|---|---|
| 墙 | 新的 1024 px 混凝土扫描（`srf_int_wall`，有模板孔和水痕），法线 1.3，光泽 0.2 加变化；墙裙油漆光泽 0.5，剥落 0.4 |
| 地 | 1024 px（`srf_int_floor`），光泽 0.24 加变化；门口一块湿区，其余零星潮斑，能映出灯和柜台 |
| 天花 | PBR，光泽 0.1 |
| 手术区瓷砖 | PBR，光泽 0.7，反射房间 |

### 道具

- 道具的方块都换成倒角盒（每条边 ≤12 mm 倒角，UV 按米算）。墙内衬和瓷砖板仍用普通方块。
- 33 个纯色材质改为“旧化”材质：颜色乘一张可平铺的磨损贴图 `int_wear.png`（PIL 生成：污渍、细斑、浅划痕），贴图的 alpha 控制光泽，所以手摸过、划过的地方亮，脏的地方哑。
- 布料、纸、液体、线缆、胶带和橡胶垫不做旧化，保持原样。

### 灯

- **冷暖分区**：工坊和柜台暖，候诊区偏冷的日光灯，手术区最亮最干净的白光，阴影里是冷色。
- 工坊灯管：3200K 左右的暖白，锥角 100°，强度 5.5，带软阴影。灯下是一池光，往墙角衰减。
- 候诊区灯管：冷白偏一点绿（旧日光灯），锥角 110°，强度 3，带阴影。
- 每根灯管加一个弱点光照亮周围天花（真灯管会打亮天花）。
- 门外楼梯间加一盏冷色射灯（雪光），透过门洞照进来，门框的影子落在地垫上。
- 暖色回弹：工坊、柜台各加一盏弱的暖点光，不投影。全区共用的夜空环境光偏冷，没有这两盏，屋里所有阴影都会发冷。
- Cool room bounce 回到冷色，降到 0.3。
- 手术区灯 (Dim alcove fill) 改为 85° 锥角、强度 4.2，让手术台成为一块亮岛。
