# B1 诊所内部：分区、墙面、灯、生活痕迹

这一轮整理的是 `Assets/RepairProps/Scenes/Temp_Berth04District.unity`（试摆场景）里的 B1 诊所内部。正式场景 `RepairProps_Clinic.unity` 没有动，按 `ART_STYLE_GUIDE_v2.md` 的规矩，布局改动先在试摆场景试。确认后再搬过去。

工具：`Assets/RepairProps/Editor/ExteriorDistrictPass.Interior.cs`，和外景用同一个 partial class 与同一套工具函数。

- 菜单：
  - `Border Repair/Interior/Apply interior pass`
  - `Border Repair/Interior/Inspect B1 clinic`
  - `Border Repair/Interior/Render interior shots`
- 批处理：`-executeMethod BorderRepair.RepairProps.EditorTools.ExteriorDistrictPass.{ApplyInterior|InspectInterior|InteriorShots}`。
- Inspect 可以加环境变量 `INTERIOR_PROBE="x0 y0 z0 x1 y1 z1;..."`，列出与这些盒子相交的全部渲染器。
- Shots 可以加 `INTERIOR_VIEWS="名字|眼 x y z|看 x y z;..."`，多出几张图。
- 可以重复运行，两次运行后场景里的名字、变换、激活状态完全一致：
  - 新增的东西都放在根节点 `09 Interior pass - B1 clinic` 下，每次删掉重建。
  - 交接物体（隔墙、货架、手术台、灯）的移动和换材质都写绝对值。
  - 项目预制体本身不改，只改这个场景里的实例。
- 素材在 `Assets/RepairProps/Scenes/Temp_InteriorPass/`：
  - `Textures/` 下：
    - 四套实拍表面（`srf_int_*`，Poly Haven CC0，见第 8 节）；
    - 告示板、钟面、挂历、员工通道牌、保养海报、处置区牌，由 Python/PIL 生成。
  - `DepthText.shader`：做深度测试的 3D 文字。
  - `Room reflection.exr`：房间反射探针，Apply 时烘焙。
  - `Materials/`、`Meshes/`：Apply 生成。
- 墙面用外景的 `Surface.shader`，新增 `_Kind = 5`（室内墙）：上半是脏混凝土，下面是 1.15 m 高的烟绿色旧油漆墙裙，交界有一条暗线，墙根积灰。

## 1. 原来的问题（实测）

- 货架横在后墙前，穿进隔墙 0.3 m；手术龙门环贴着隔墙和右墙。
- 客人一进门就能走到工作台和手术台，等候区与工坊之间没有任何分隔。
- 右前方 (x 0.3–3.5, z 0.2–3.5) 一片空地。
- 墙和天花是铆接钢板，与风格指南的“混凝土 + 烟绿旧漆”不符。前墙的室内一侧露着外景混凝土，街面首层侧楼的盒子还穿进室内 12 cm。
- 地面其实看不见：港口水面是一整块盒子（108 × 0.34 × 51，顶面 y 0.05），比地坪（y 0）高 5 cm，房间像泡在黑水里。
- 天花上有一块冷蓝光斑（Cool room bounce），灯具是发白的方盒子。
- 3D 文字都用 Unity 字体材质，会画穿墙：楼梯口的 “B1 REPAIR” 反着透进地下室，“收件”从柜台背面也看得到。
- UNIT 07 的维护角套件（DockCornerV2）在交接里是关掉的，半截插在门口墙里。

## 2. 分区

柜台不动（街口要能看到它）。以柜台为界：
- 门这侧是客人区：入口、收件托盘、等候椅。
- 柜台后是工坊：工作台、UNIT 07 维护位、货架。
- 手术区在右后，有隔墙和帘子。

| 物体 | 改动 |
|---|---|
| 隔墙 | 中心 x 1.12，长 2.76 m (z 3.55–6.31)，到帘子线为止，手术区成了三面围合的隔间 |
| 手术台、龙门 | x 2.40；环 x 1.30–3.50，不再碰墙 |
| 货架和货物 | 转 90°，背贴隔墙的工坊一侧，货架正面朝工作台和维护位 |
| 地上三个收纳箱 | 是货物网格的一部分，离地 33 cm 浮着（交接里就是这样，被水面遮住了）。下面垫一块跳板加三块混凝土砌块：潮湿地下室防潮的常见做法 |
| DockCornerV2 | 打开，挂到后墙 UNIT 07 周围：充电面板、运行/充电/故障灯、表、备件、脐带缆、地垫、接油盘 |
| 员工通道门 | 从柜台斜翼末端到隔墙前端，齐腰高，旧绿漆钢栏，牌子朝客人一侧（员工通道 / 非请勿入） |
| 地垫 | 柜台后店员站的位置一块、工作台前一块 |

## 3. 表面

| 部位 | 材质 |
|---|---|
| 左右后墙、隔墙、前墙内衬 | 脏混凝土上部 + 烟绿旧漆墙裙 (1.15 m) + 墙根积灰 |
| 地坪 | 磨损水泥地（偏暖灰） |
| 天花 | 旧涂料天花，法线减弱到 0.55，不抢眼 |
| 手术区三面 | 白瓷砖到 1.8 m，上沿有收边条 |

- 前墙的门两侧和门顶加一层内衬，表面到 z 0.29，把外景混凝土和穿进来的侧楼盒子都盖住。外景那一面不动。
- 港口水盒整体下降 8 cm（顶面 y -0.03）。这样所有地面都在水面之上，港口从街上看不出差别。

## 4. 灯

- 两根日光灯管替代原来的方盒子：
  - 工坊：暖白，带软阴影，是房间的主光。
  - 等候区：中性白。
- 门内挂一只带铁丝罩的裸灯泡：暖色，照门口地垫和托盘前站的人。
- 交接的灯：
  - Cool room bounce：冷蓝改成暖灰的低位补光（i 0.9）。天花上的蓝斑没了。
  - Dim alcove fill：改中性白（风格指南：手术位是中性白）。
  - Low dock fill：调弱到 1.8。
- 原壳体的两个灯具盒改成灯管材质。
- 房间加一个盒投影反射探针，Apply 时烘焙。烘焙时只临时把房间里的物体标成反射静态，之后改回原值。钢件、湿地垫不再反射外面的雪夜天空：之前推车和栏杆发白，就是这个原因。

## 5. 客人区

- 三连排候诊椅沿右墙，朝柜台和门；中间一张座面裂了，用灰胶带十字贴着；端头座位上有张折起来的报纸。
- 椅子旁一台充油电暖器，琥珀指示灯，插头接到墙上插座。
- 门边角落：饮水机和一摞纸杯。
- 前墙：告示板（本店规则：只接夜班、概不赊账 / 价目 / 拾到东西的条子 / 港务通告），上方挂钟。
- 椅子上方是义体冬季保养海报。
- 进门：一块湿橡胶地垫、一滩化雪水、一桶湿雨伞。

## 6. 手术区

- 吊轨帘子在隔间口，拉到右墙收着。
- 轨道下挂“处置 · 手术 / 叫号后进入”牌。
- 不锈钢器械推车放在台尾与隔墙之间。
- 后角有一只医疗垃圾桶，芥末黄盖子。

## 7. 工坊和管线

- 左墙柜台旁：挂钩上一件橄榄色派克大衣，还有一本挂历，还停在十月（北港航运赞助）。
- 柜台上方沿左墙挂一串旧节日彩灯，是屋里唯一一点过冬的暖意，没有单独打光。
- 收银盒旁一只保温瓶；维护位的线槽上搭着一块晾着的抹布。
- 后加的暖气管从前墙高处进来，沿等候区天花下走，在手术区之前拐进右墙（让开龙门环）。管上一处缠胶带的接头在滴水，下面一只蓝桶接着，墙上留着一道水渍：墙上的渗水都要能追到一根管子。

## 9. 检查

- Apply 连续跑两次，场景里所有物体的名字、位置、旋转、缩放、激活状态完全一致。
- `^BorderRepair\.RepairProps` EditMode 测试 132/132 通过。
- 截图前关掉异步着色器编译，每个视角渲两帧。否则批处理的第一帧会出现占位色和串色的材质。

## 10. 已知限制

- 新增道具都是基本体拼的（椅子、电暖器、推车、饮水机等），比例和摆放是定稿的，造型可以以后换模型。
- 工作台 RepairBenchV2 没动（桌子会另外设计）。台子上方原壳体的“Bench task fixture”还是那块斜放的灯盒。
- 货物网格里那三个收纳箱靠跳板托着。真正的修法是在源模型里把它们落地或放上货架。
- 只在试摆场景里做了。要搬进 `RepairProps_Clinic.unity`，需要先确认布局，再把同一个 pass 对准那个场景跑。那边坐标不同，隔墙和货架的绝对值要重新量。
