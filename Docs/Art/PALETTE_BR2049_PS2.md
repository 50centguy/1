# 色板：《银翼杀手 2049》× PS2 复古工业

这是美术规范（`ART_STYLE_GUIDE_v2.md`）下的色彩约束，可以直接填进 Unity 的材质和灯光。色板由用户给定（2026-11-19），本文件只补充"在 Unity 里填在哪、填多少"。

## 比例

**60% 冷灰底色 + 25% 暗部阴影 + 15% 局部光源点缀。**

## 色板（用户给定）

| 角色定位 | 颜色名称 | HEX | Unity 用法 |
|---|---|---|---|
| 外景主调（60%） | 雪夜雾霾青 | `#3B4B54` | 外景雪雾 Fog Color、远景企业黑塔剪影、飘雪天光底色 |
| 外景/室内基底 | 石青水泥灰 | `#253238` | 混凝土板楼、防波堤海墙、地下室潮湿墙体 |

## 三条规则（用户给定）

1. **外冷内暖只留两组对比。** 外面只用 `#3B4B54`（冷雾）压住环境，门口和工作台用 `#E89A3C`（琥珀暖光）把玩家视线吸进来。
2. **坚决禁用高饱和品红/紫红霓虹。**
3. **人物贴图压低 15%～20% 饱和度。** 小遥的反光背心、森田的工装和七号外壳，别用纯白或亮黄，往 `#3B4B54` 方向灰一点。

## 在 Unity 里怎么填

表里的 HEX 是**画面上**的颜色。材质的 Base Color 是反照率，还要乘灯光、再混雾，所以材质值和 HEX 不会一样。外景已按下面的值落地（`Assets/RepairProps/Editor/ExteriorDistrictPass.Palette.cs`），其他场景照这个思路填。

### 雾和天光

| 项 | 值 |
|---|---|
| Fog Color | `#3B4B54`（Exponential Squared，密度 .022 不变） |
| 方向光（阴天天光） | `#A8BDC7`，强度 .445，阴影强度 .6（阴天：有形状，但不压成黑块） |
| 冷补光（街道、上层平台） | `#9EB2BD` 强度 4、`#9EB5C2` 强度 3.4 |
| Ambient | 没改（Flat `#4F5966`）。它对室内也生效，室内调色时一起定 |

### 材质反照率（外景）

| 用途 | Base Color（线性前的 sRGB 值） | 对应色板 |
|---|---|---|
| 预制混凝土板楼 | (.26, .32, .35) × 中性灰贴图 | 石青水泥灰 `#253238` |
| 远处粉刷楼 | (.32, .35, .36) | 同上，偏亮一点拉开远近 |
| 铁件、栏杆、管道 | `#4E433B` × 1.1，掉漆处露锈 | 冷铁锈褐 |
| 雪 | (.60, .66, .70) | 雪在雾里读成冷灰 |
| 压实的雪、车辙、脚印 | (.20, .24, .26)，只在有人走、有车压的地方出现 | 接近深铁青黑，但不发黑 |
| 夜里的窗玻璃 | 深青灰 + 边角霜花 | 深铁青黑 |

### 自发光

| 用途 | 颜色 | 强度 |
|---|---|---|
| 门口灯箱打光、门内透出的光、亮着的窗 | `#E89A3C` | 窗 ×.85（亮）/ ×.4（暗）；招牌打光点光源 2.1 |
| 全息投影 | `#6BE0E8` | 1.0–1.5（远景楼体上的企业横幅 2.2，固定雾化 .45） |
| 屏幕（充电桩、岸电读数、船的绿舷灯） | `#5CE67E` | 1.1–1.8 |
| 障碍灯、摄像头、锁死、红舷灯 | `#C93B3B` | 1.8–3.0；远景塔顶灯固定雾化 .35–.4，穿过雾也能看见 |
| 街灯、码头灯、院门灯管 | 冷白 `#A9BCC4` / `#B2C4CC` / `#BFD1D1` | 不再用钠灯黄、琥珀 |

### 人物（本轮未处理，规则先写在这）

- 贴图或材质颜色向 `#3B4B54` 拉 15%～20%：`新色 = lerp(原色, #3B4B54, 0.15~0.2)`，或者 HSV 饱和度乘 .8。
- 反光背心的荧光黄、工装的白、七号外壳的白都要先压，再进场景看。

## 怎么验

用 `ExteriorDistrictPass` 的截图（`Border Repair/Exterior/Render review shots`）粗算像素占比：
- 亮度 < .12 记为暗部；
- 饱和度 > .4 且最大通道 > .35，或亮度 > .85，记为光点；
- 其余记为冷灰。

外景第二轮的结果：

| 视角 | 冷灰 | 暗部 | 光点 |
|---|---|---|---|
| 街对面看 B1 入口 | 81% | 18% | 1.1% |
| 沿街 | 76% | 23% | 0.7% |
| 路口 | 87% | 13% | 0.7% |
| 04 泊位 | 94% | 6% | 0.2% |
| 楼梯口 | 63% | 36% | 1.1% |
| 回程 · 回望 B1 | 78% | 21% | 0.4% |

**按像素面积算，光点远到不了 15%。** 外景把 15% 当作颜色预算：琥珀、青、绿、红只出现在灯、屏幕和投影上，不铺进环境色。如果要按面积接近 15%，需要更多亮窗和投影，这和"克制"冲突，要另外决定。码头一段雪面大、暗部少，是现在离 25% 最远的地方。
