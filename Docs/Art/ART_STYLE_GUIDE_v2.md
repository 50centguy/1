# 《边境维修站》美术规范 v2

2026-11-19。在 v1（`Documents/Codex/2026-09-29/border-repair-station-art/ART_STYLE_GUIDE_v1.md`）的基础上加入三部参考作品的取舍。v1 的色板、镜头和验收方法继续有效，本文只写**新增和改变**的部分；两者冲突时以本文为准。

## 一句话

**冬夜里一个小窗口后面的日常维修，科技是旧的、借来的，界面是清楚的。**

克制的赛博朋克负责世界观，PS2 时代的实时 3D 负责画面质感。三部参考各取一层：《IT'S WINTER》取日常和安静，《I Have No Change》取窗口和顾客，《SIGNALIS》取界面和制度的图形语言。

## 参考作品：取什么，不取什么

参考的是方法，不是外观。不复刻任何一部的角色、字体、图标、标志、配色组合或具体场景。

### 《IT'S WINTER》：日常的重量

一个冬天的居民楼，玩家在小厨房和楼道里"什么也不做"。气氛靠阴天、雪、旧楼道和生活杂物撑起来。

**取：**
- **生活先于设定。** 铺子首先是有人过日子的地方：保温杯、晾着的抹布、贴在墙上的排班表、过期日历、电暖器。义体和终端混在这些东西里，不站 C 位。
- **窗外的冬天。** 采光口、门缝、楼梯口能看到雪和阴天的冷灰光。室内暖、室外冷，是全片最基本的冷暖关系。
- **安静的间隙。** 两单之间留"没事做"的时刻：灯管嗡声、暖气滴水、窗外偶尔经过的车灯。画面不在这时候塞新信息。
- **普通的光。** 日光灯、钨丝灯泡、电视/CRT 的余光。光源都是现实里买得到的灯，不是装饰灯带。

**不取：** 没有目标的漫游。我们是经营 + 维修，任何时刻玩家都要能找到当前工位。

### 《I Have No Change》：窗口后面的人

第一人称、夜班小卖亭，顾客一个个来到窗口前，每人带一段故事。

**取：**
- **柜台就是舞台。** 柜台窗口是顾客出场的取景框：顾客上半身、手、递过来的东西在同一个画面里。这是支持"柜台前置"布局的主要理由。
- **东西替人说话。** 顾客的身份先由他递过来的物件和手讲出来（湿的对讲机、自己缠的胶布、旧臂压低托盘），再由台词补充。
- **小空间的密度。** 柜台后面伸手可及的范围里堆满东西，但当前递交的物件永远最清楚。
- **节日的一点暖。** 冬季可以有一串旧彩灯、一张贺卡、一个小供品。只占角落，不改变整体色调。

**不取：** 小卖亭的商品陈列、收银交互和地域符号。我们的柜台是维修铺的收发台，不卖货。

### 《SIGNALIS》：清楚的界面，制度的图形

低面数 3D 加清晰的像素图形，复古科技界面，地图和终端信息读起来非常利落。

**取：**
- **世界可以模糊，界面必须锐利。** 3D 画面经过 PS2 后处理会变糊，但 HUD、文字和图标**不进入后处理**，按原生分辨率清晰绘制。
- **制度有一套图形语言。** 港务局、租赁公司和监管方各有统一的标识格式：编号、条码、封条、表格栏位、印章。用同一套规则生成，玩家看多了就能认出"这是港务的东西"。
- **克制的色板加一个警示色。** 大面积低饱和，只有一个高饱和强调色。我们的强调色是 v1 的工作琥珀；故障朱红只占小面积。
- **不稳定只用在关键时刻。** 画面抖动、信号撕裂只在剧情节点出现（例如神经接入、远程锁死触发），平时界面稳定。

**不取：** 恐怖、血腥、怪物；动漫风格的角色；它的红白配色、字体、图标和标志。

## 由此调整的规则

### 布局（待定）

参考《I Have No Change》，倾向 v1 的"柜台在前、维修台在柜台后、手术位后移"。正式改动前要在试摆场景里跑一遍完整动线（见 `Docs/DEV_PLAN.md`）。

### 场景与道具

- 每个工作区至少有一件与工作无关的生活物件（杯子、外套、饭盒、贴纸），放在不挡工位的位置。
- 至少一处能看到室外：门口楼梯的雪，或高窗外的冷光。
- 装饰性灯光只允许用现实灯具（灯泡串、旧霓虹管、指示灯），不用发光灯带勾边。
- 义体和高科技设备都是旧货：有序列号、租赁标签、补漆、更换过的螺钉。不出现全新、无磨损的高科技外壳。

### 人物

- 成年人比例，低面数，脸部简单但轮廓好认。不用动漫比例和大眼睛。
- 身份靠服装和随身物（安全帽、巡检服、自缠胶布、旧臂）表达，柜台视角下就能读出来。

### 界面

- HUD、标签、文字在 PS2 后处理**之后**绘制，或者不受它影响。（待核对：现在的义眼 HUD 是否被后处理影响。）
- 制度标识统一格式：`机构缩写 / 编号 / 状态`，例如 `NSP PORT · LEASE 0412 · VOID IF OPENED`。同一机构用同一字体、同一边框。
- 剧情节点之外不用故障特效。神经接入的青色接入动画属于"关键时刻"，可以保留。

### 声音（附带）

安静的间隙要有环境底噪：灯管、暖气、远处港口、雪天的闷声。和画面一起营造"夜班只有你一个人"。

## 验收补充

在 v1 的同机位验收之外加三条：

| 检查 | 通过时 |
| --- | --- |
| 柜台取景 | 柜台正常站位能同时看到顾客的手、递来的物件和盘沿；物件是画面里最容易认出的东西。 |
| 生活感 | 截图里每个工作区能找到至少一件生活物件，且它不比当前工件更显眼。 |
| 界面锐度 | 1280 × 720 下 HUD 小字笔画清晰，没有被抖色、量化或扫描线吃掉。 |
