# 第二晚：卸下整个引擎抱到维修台上修（2026-10-09）

分支 `feat/clinic-carry-to-bench`（接在 b5b7228 之后），工作树 `clinic-bench`。

**下面都是程序输入 / 程序拍图，不是真人试玩。**

## 新流程（统一诊所第二晚，七号 RB-07）

1. 走到七号旁边，点左引擎：检查（说明故障、要卸下来修）。
2. 再点左引擎（或内侧连接键）：拔下辅助线缆、松开连接键。
3. 再点：整个左引擎卸下来，抱在手上（挂在玩家视角前下方，碰撞关闭，七号的动画暂停）。
4. 走到维修台，点台面上的落点：引擎放在操作垫中间，锁扣朝向玩家。
5. 在台上按原来的零件流程修：清理进气口 → 扳开两个锁扣 → 取下上盖翻面放到垫子左边 → 换轴承 → 装回上盖 → 扣回锁扣。
6. 点修好的引擎：抱起来；走回七号，点左侧安装位：装回（回到原来的父节点和原位姿，偏差 < 0.5 mm）。
7. 点左引擎：插回线缆、拧紧连接键 → 去维修座通电 → 松开夹具离座复测。

会被拒绝的操作：抱着引擎去通电；引擎还在台上就通电；装回了但线缆没接就通电；要拆右引擎（对照）。

零件不再从七号身上“飞”到桌上：拆装零件都发生在引擎已经放在台上之后。

## 占位表现（需要美术 / 动画）

- 没有手部和搬运动画：引擎直接挂在视角前下方。
- 拔线 / 松键只用连接键位移 8 mm 表示，线缆本身不动。
- 放到台上、装回七号都是瞬间到位（没有过渡动画）。
- 台上空位按包围盒近似搜索，不是网格级碰撞；引擎底面架在托架块上（高出台面 4.4 cm）。
- 进气口在台上朝上，玩家站在台边斜着看会被进气唇口挡住；所以给堵塞加了一个罩住唇口口沿、顶部高出唇口 1 cm 的点选盒（清理后随堵塞一起关闭）。在七号身上时这块也算点到引擎，效果一样是拔线。

- 瞄准点优先选“四周偏 0.4° 也选中目标”的方向，不再选目标边缘。
