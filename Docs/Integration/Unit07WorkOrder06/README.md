## 2. 分工与供电

| | 维修座 `Unit07DockController` | 工单 `Unit07WorkOrder06Session` |
|---|---|---|
| 负责 | 停靠、夹具、断电 / 恢复供电、转子、离座 | 检查、拆卸顺序、维修选择、装回、通电前检查、悬停 / 负载复测 |
| 供电 | **唯一决定者**。只能从断电开关（鼠标点击）操作 | **从不调用**供电接口。只通过 `IDockServiceCompletionGate.CanFinishService` 回答“能不能恢复供电” |
| 工单里的“停靠 / 断电 / 恢复供电” | — | 不由玩家按按钮，而是每帧从维修座的真实状态同步（`Sync()`） |

**同步规则**（工单阶段只会前进，不会被维修座以外的东西推进）：

- **停靠**：维修座进入 `Clamped`（或之后的 `SpinningDown` / `RotorsStopped`）时成立。
- **断电**：维修座 `RotorsStopped`（已断电、叶轮停稳）时成立。只在减速中不算。
- **恢复供电**：通电前检查已通过，维修座经工单放行后真的通电时成立。
- **防御**：如果在检查到通电前检查之间看到维修座通电（只可能是接线错误、绕过了工单接口），工单记录安全故障 `SafetyFault`，工单不前进，拆装继续被拒绝。

**安全规则**：

- **检查、拆卸、维修选择、装回、通电前检查**：维修座必须是 `RotorsStopped` 且断电。减速中被拒绝，原因写明“叶轮还在减速转动”。
- **通电前检查**：13 步全部按逆序装回、叶轮停稳、零件盘和磁性零件盒都已放回原位（读维修座 `DockPickable` 的真实状态）。
- **允许结束维修**（`CanFinishService`）：
  - 装回完成并且通电前检查通过时才放行。
  - 之后的复测阶段和工单完成后也放行（期间不能再拆）。
  - 其它阶段都拒绝，并给出原因；原因直接显示在维修座 HUD 上。
- **悬停 / 负载复测**：维修座必须是 `Undocked`（离座悬停）、通电、转子在悬停转速。加速中、夹着、落座未离座、升起中都拒绝。
- **复测失败**：
  - 工单回到“停靠”，并清掉通电前检查。
  - 玩家点夹具握把重新落座、夹紧、断电。
  - 叶轮停稳后直接进入重新拆卸（沿用导入会话的规则：第二轮不重复检查），之后再走一遍装回、检查、放行、离座、复测。

**EditMode 测试明细**：

- **ID**：工单 ID、机器人 ID、3 个检查点、13 步；初始提示不含“六号”；记录都带 ID。
- **同步**：工单阶段只由维修座真实状态推进。没夹紧不算停靠，减速中不算断电；夹紧后又离座时停在断电，重新夹紧后继续。
- **完整顺序**：
  - 越序拆卸、非逆序装回被拒绝。
  - 装回后未检查不放行。
  - 悬停复测失败 → 重新停靠 → 第二轮直接拆卸；负载复测失败 → 第三轮；最后通过。
- **安全**：
  - 5 个工作阶段 × 10 个非停转状态 × 5 种操作，共 250 次，全部拒绝。
  - 被拒绝的操作不记入工单。
- **复测**：除离座悬停外一律拒绝；复测前又落座断电时，不能重新拆装，但仍放行恢复供电。
- **放行**：逐个工单阶段核对；装回差一步不能检查、不放行。
- **零件盘**：零件盘没放回时通电前检查被拒绝。
- **绕过接口**：维修座绕过接口通电时记录安全故障，工单不前进。
- **真实维修座**：
  - 用真实维修座和七号预制体，按 1/60 s 推进：每个阶段都试着恢复供电，都被工单拒绝。
  - 每次工单操作都不改变维修座状态、供电、夹具、手柄。
  - 包含复测失败、重新停靠、第二轮、通过的完整往返。
  - 真实取下零件盘时，通电前检查和恢复供电都被拒绝。

**PlayMode 测试明细**：

  - 没有 `ManualServiceCompletionGate`。
