## 2. 结论

### 第一晚端盘（`tray_handoff.md`，程序先看）

- **只有一个现成托盘**：`Unit07ServiceDock/Dock_PartsTray`。
  - 盘体 260 × 180 mm，盘壁高 40 mm；
  - 两端提手横杆沿前后、管径约 10 mm、中心距 **303.4 mm**；
  - 原点在盘底中心；单一网格，没有握持挂点。
  - 它不是玩家换轴承时用的暂存盘（那些是工作台托盘），所以没有占用冲突。但 `holdPoint` 是空的，`Take()` 现在不生效。
- **用现有托盘双手端不起来**【实测】：夹爪在已有动画角度内最近相距 405 mm，最接近的姿态每只手还差 41 mm。
- **不加资源的退路**【实测】：右手单手纵握一端提手。正常 / 左侧下沉 3–6° / 盘面倾斜 ±4° 三种参考姿态都能摆出，落座全程碰不到维修座。但盘离夹爪支架只有 3.6 mm。
- **要双手端**：最小补件是提手中心距 ≥ 460 mm（500–530 mm 最好）。
- **双写风险**：所有动画片段都写全部骨骼，端盘期间手臂只能有一个写入者。
- 第一晚的端盘镜头都看不到轴承，不会提前给出诊断。

### 第二晚整台左引擎替换（`gap_list.md`、`assembly_inventory.csv`）

- **能不能用现有资产换整台**：几何上可以。拆下、搬运、落点、两台同时摆放都量过可行。卡住的是程序实现（E1、E3、E4）和线缆的拔下状态（E2）。
- **总成成员**：`Engine_L_Hinge` 骨骼下 42 个对象随引擎走，都是独立网格 + MeshCollider：
  - 外壳 8 件、锁扣 2 件；
  - 内部 14 件 + 内部引线；
  - 转子 3 件；
  - 连接座、连接键、螺栓；
  - 两个引擎端插头；
  - 故障包 8 件（积尘 / 纤维、磨损轴承 + 碎屑、保养贴纸）；
  - 另有一个维修座加的检查代理。
- **留在机身的有关件**：
  - 插座、插座旋钮；
  - 两个机身端插头；
  - 内部线束和两端插头、主板接口；
  - 安装轨、硬点板（只作参照，不与引擎接触）。
- **跨界的**：两根蒙皮外露线缆。
- **唯一的机械接口**：连接键 ↔ 机身插座。实测：先拔螺栓（向上 25 mm 脱开），引擎外滑 20 mm 就离开连接键。连接键应该留在机身里，虽然它在层级上挂在引擎骨骼下。
- **线缆**：两根外露线都是约 5 cm 的蒙皮跳线，只绑 Body / Engine_L_Hinge 两根骨骼，没有拔下状态。内部引线和机身线束都不跨界。
- **路线**：
  - 侧拔 400 mm，最小间距 17 mm 起，逐步增大；
  - 引擎最低点升到 1.08 m，水平移到操作垫，转 90° 落下；
  - 全程最小间距 27.7 mm。
- **落点**：
  - 操作垫有 53 个可放整台引擎的位置，旧件 + 新件可以同时放；
  - 零件盘、托盘、轴承盒都装不下整台引擎。
- **接近 / 可见**：连接键、螺栓、连接座、黄线引擎端插头在现有游戏镜头里全部 0% 可见（上盖装着时），需要新的近景镜头。
- **替换件**：可以复用左引擎全部网格和材质。但材质与右引擎共用，外壳印着 “L-03”。要看出是新件，需要一个材质变体，不需要新几何。
- **旧保养贴纸**：随旧上盖走，**去向交策划决定**。

## 4. 实测 / 推断 / 未验证

- **实测**：上面所有尺寸、间距、可见比例、关节角、权重和端点。
- **推断**：
  - 3.6 mm 的盘—支架间隙在动作过渡中会不会擦到；
  - 引擎直立放在垫子上稳不稳；
  - 补件尺寸（提手 460–530 mm）只用假想横杆求解过，没有实际网格。
- **未验证**：
  - 真人鼠标试玩、VR；
  - 动画实际播放效果（本次只有静态姿态）；
  - 上盖拆下后固定件的可见度；
  - 目标硬件性能；
  - 盘里有零件时的表现。
- **已知测量限制**：
  - 蒙皮线缆没有碰撞体，不挡可见性射线；
  - 维修座 / 工作台只有部分物件有碰撞体，所以可见比例对它们偏乐观；
  - 关节角范围取自已有 9 个片段，不是机械极限。
- **审计过程中修正过的错误**（以最终数字为准）：
  - 托盘本地 Z 才是向上轴（一开始当成了 Y）；
  - 工作台上的义体占位道具在 B 场景里是隐藏的，一开始误算为障碍；
  - 渲染步骤一开始没有初始化夹爪，图上的距离不对。
