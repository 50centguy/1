# 最小缺口清单（按阻断程度排序）

**分类**：

| 分类 | 含义 |
|---|---|
| 可复用 | 现有资产直接能用 |
| 摆位 / 材质调整 | 不改几何 |
| 缺几何 | 需要新建或修改模型 |
| 程序实现 | 美术不用动 |
| 待核实 / 待定 | 需要策划或真人确认 |

**阻断程度**：

| 级别 | 含义 |
|---|---|
| P0 | 不解决就做不出该段 |
| P1 | 能做，但表现明显不对 |
| P2 | 观感 / 后续 |

“最小范围”只写够用的最小补件；补件依据清单另行派单，本单不建资源。所有“实测”都来自 `8dc8bb8` 的 Unity 布局 B 场景（只读、不保存）。

## 不是缺口（已有，不要重复建）

- **总成网格**：随引擎的 42 件（含故障包件）都是独立对象，各有自己的渲染器和 MeshCollider。见 `assembly_inventory.csv`。
- **内部线路**：内部引线 `Engine_InternalLead_L` 两端都在引擎内：一端在黄线引擎端插头旁 2.1 mm，另一端在绕组旁 2.5 mm，不跨接口。机身内部线束 `Harness_Engine_L` 从主板接口通到黄线机身端插头，整条留在机身。两者都不用解除绑定。
- **插头**：外露线缆两端的插头（`*_PlugBody` 留机身，`*_PlugEngine` 随引擎）都有独立几何和拆卸方向属性。
- **机械接口**：引擎与机身之间唯一的接触是连接键 ↔ 机身插座（`BodySocket_L`）；`EngineAnchor_L` 离插座 12 mm。
