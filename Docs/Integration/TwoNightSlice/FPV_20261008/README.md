# 七号场景第一人称自由移动（2026-10-08）

分支 `feat/first-person-move`（从 `integ/two-night-slice` 088fac4 分出），工作树 `BorderRepairStation_fpv`。今天的真人试玩候选包（`BorderRepairStation_slice\Builds\TwoNightSlice_N1N2_20261005-n1n2s`）不受影响。

**下面的“通过”都是程序输入（脚本给移动、转头、鼠标 / 键盘事件），不是真人试玩。手感（速度、灵敏度、晕不晕）没有人试过。**

## 做了什么

| 项 | 内容 |
|---|---|
| 范围 | 七号场景 `Unit07_Night`（第一晚停靠、第二晚检修）。柜台场景是纯界面，不变；七号鼠标核心场景（`-twoNightCore`）没有第一人称，保持固定机位，作回归入口 |
| 操作 | WASD / 方向键移动，Shift 快走，C 切换蹲下（按住 Ctrl 也蹲），鼠标转头；准星对准后左键操作、右键观察；Tab 或 Esc 放开鼠标去点界面，点一下画面（不在按钮上）锁回准星 |
| 伸手距离 | 1.3 m。超出时左键不操作，反馈“够不着…走近一点”。观察沿用原来各项的看清距离（轴承 0.45 m 等），看不清时仍可切固定机位近看 |
| 固定机位 | 底部镜头栏保留为“近看”。进入后直接用鼠标点（和原来一样）；按 WASD 或「← 行走」回到行走 |
| 流程自动切镜头 | 第一人称下不再把视角拉走（`FirstOrderCameraRig.Auto`）；固定机位场景照旧 |
| 第一晚 | 端盘演出仍用固定的总览镜头看完（期间不能走）；演出结束后回到行走 |
| 自动放开鼠标 | 手册展开、出现“登记内部维修单”按钮、夜末面板时：鼠标放开、停止移动 |
| 场景改动（只在发布场景） | 加玩家（CharacterController，半径 0.14 m，眼高 1.55 m，蹲 1.12 m）；房间正面和右前方没有墙，加了看不见的边界（只挡行走，点选射线忽略）；凳子从工作台和维修座之间挪到前左角（不挪就走不到七号背面）。原 prefab、FBX、材质没改 |
| 显示名 | 悬停提示不再显示物体名（如 `Unit07_EngineL_InspectProxy`），改为“七号左引擎”“维修座：夹具握把”等；状态栏镜头显示“行走” |

两处要知道的限制：
- 去七号背面（扳后侧锁扣）的唯一通道在打开的抽屉和左夹具之间，只有约 0.38 m，所以人物做得较瘦（半径 0.14 m）。
- CharacterController 的最小移动距离设为 0：默认 1 mm 在高帧率（自检里约 650 帧 / 秒）下会让慢速移动走不动，测试里就是这样暴露的。
