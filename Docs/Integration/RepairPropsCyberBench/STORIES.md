# 物件里的故事（2026-10-21）

所有故事都只通过维修工能看到的东西讲出来：

- 部件上的痕迹，作为检查发现；
- 只读核对报告的元数据，作为测试结果；
- 物主说的话，作为工单和来电。

私人内容一律不打开。四件物品串在同一个主题上：**有人（或某个东西）在替一个不在了的人回应。**

代码在 `Assets/RepairProps/Runtime/RepairPropStories.cs`：

- `Backstory` 写进工单的「物件来历」；
- `Finding` 是部件检查发现的第一行；
- `TestNote` 接在测试结果后面。

来电台词在 `ClinicCallRuntime.cs`。

## 1 · 信号接收器 —— 凛（三号管廊夜班巡检）

| 位置 | 内容 |
|---|---|
| 工单 · 物件来历 | 兄妹都是巡检员，哥哥的呼号是「巡检 07-B」。去年七号泊位漏压，他没有上来。这台是他的值班机，存着每晚 02:10 的呼叫时段。 |
| 后盖 | 记号笔写的「07-B」，安全帽灯磕出的痕迹 |
| 电池盒 | 胶带：「哥 02:10 别关」 |
| 射频小板（故障） | 盐结晶：机器泡过海水 |
| 顶部护条 | 港务贴纸：「下井前报呼号」 |
| 信号测试通过 | 02:10 频段收到一次自动应答，呼号仍是「巡检 07-B」，发信方是 NSP 自动巡检单元 |
| 来电 patrol-receiver | 港务拿哥哥的巡线记录训练了自动巡检，连呼号都没改。「它不是他……可它还在那条管廊里，替他走那一圈。」 |

参考：

- 《攻壳机动队》里被植入虚假家人记忆的清洁工；
- Ted Chiang《软件体的生命周期》：被留下来继续运转的数字存在。

| 位置 | 内容 |
|---|---|
| 工单 · 物件来历 | 潮汐回收船上收来的旧义体里拆下的装卸义手卡匣，存着那只手的校准数据（“手感”） |

参考：

- Gibson《Johnny Mnemonic》：携带自己读不了的数据。

参考：

- 《赛博朋克 2077》里的芯片与超梦：存储的情感。

## 设计约束

- 维修工从不播放、复制或格式化私人内容。故事只来自物理痕迹、只读元数据和当事人自己的讲述。
- 文本只放在 `RepairPropStories.cs` 和来电里，流程本身（命令、条件、测试判定）没有改动。
