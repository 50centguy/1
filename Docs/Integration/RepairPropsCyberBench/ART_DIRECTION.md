# 诊所场景美术统一规则（2026-10-20）

## 依据

- **概念图**：`clinic-ring-v2` 02、03、04、05。环境是绿灰色钢板；暖色工作灯；绿色 CRT 屏；手术台在画面中心。
- **参考库**（`reference-library/images/pinterest-reference2`）：
  - *Black Clinic*（Mona Lisa Overdrive）：手术椅上方一道强烈的青白光锥，周围压暗；远处另一间屋子整间是暖红色。**一个区域只用一种色温。**
  - *昏暗工业维修大厅*：一个大顶光，四周很深，只有几处小的红、蓝点缀，空气里有雾感。**亮度分层明确。**
  - *绿色低照度工作室*：整个房间统一在绿 / 青一个色相家族里，荧光灯管做光源。**色相统一。**
  - *旧化科幻控制工位（宇宙制品厂）*：低饱和的青灰底色，暖色只出现在小物件上（琥珀指示灯、红水壶）。**大面低饱和，饱和色只留给小东西。**
  - *Tick's Hideout*：暖灯区、绿屏区、红警示区分开摆放，互不混色。
- **网络资料**：
  - Robert Yang 在 GDC 2018 的“如何给关卡打光”：先定好全局环境光和主光，再用点光、聚光突出路线和重点，用对比引导视线，同类物体用同样的打法。见 [GDC 2018 How to Light a Level](https://www.blog.radiator.debacle.us/2018/03/gdc-2018-how-to-light-level-slides-and.html)。
  - 一般性的打光指南：色温是最便宜的情绪旋钮；“冷色主调 + 暖色室内光池”是典型的夜间避难所氛围；用灰度检查画面层次；每个光都应该有一个看得见的光源。见 [Lighting basics](https://bugnet.io/blog/lighting-basics-that-transform-your-games-look)、[Game lighting design](https://gamineai.com/blog/game-lighting-design-creating-atmosphere-and-mood-in-your-games)。
  - PS2 时代的做法：距离雾、简单烘焙光、低清贴图，以雾限制视距、营造氛围（如 Silent Hill、Ico）。见 [Unity 讨论：做出 PS2 观感](https://discussions.unity.com/t/making-a-game-look-like-a-ps2-title/917427)、[Retro Fog shader](https://halfhuman.itch.io/retro-fog-shader-for-unity)。

## 规则

1. **色温分区**：
   - 房间整体：昏暗、偏冷的青绿荧光（顶灯管、天花、入口），强度压低；
   - 工作区：暖色钨丝灯光池（维修台台灯、柜台工作灯、维修座工作灯），每处光都要有一个看得见的灯；
   - 手术台：中性白的无影灯，是全场最亮、最集中的焦点；
   - 同一个区域里不再冷暖混打（维修台近看的冷色补光改成中性偏暖）。
2. **亮度分层**：最亮的是手术台光锥和维修垫；其次是柜台和维修座；墙、角落、天花最暗。远处由距离雾吃掉细节。
3. **色彩预算**：
   - 大面积（墙、地、柜体、龙门、机械臂主体）一律低饱和：绿灰、钢灰、旧象牙；
   - 饱和色只用在小面积上：工具把手、标签、指示灯；
   - 红色只用于警示和故障；
   - 绿色发光只用于 CRT 和屏幕；
   - HUD 用琥珀色，和暖色光池同一个色系。
4. **后期**：
   - 撤掉之前那层强调色（分离色调、暖色滤镜、色温 +35）；
   - 房间只做很轻的统一：对比稍高、饱和稍低、色温略冷，靠灯光本身的颜色出暖色；
   - 关掉胶片颗粒，避免和 PS2 抖色叠加成噪点；
   - 适度辉光，让灯和屏幕有光晕；
   - 暗角稍加，把视线收向中心；
   - PS2：保留低分辨率和抖色，把色度渗色降低，减少彩色拖边。
5. **噪点控制**：
   - 新三件的锈斑减量；
   - 龙门机械臂主体改成深色钢，不再是一排亮象牙色挂在头顶；
   - 场景里的白色英文立体字改成小号、低亮度的琥珀色标识；
   - 和龙门无影灯重复的手术点光关掉。

## 赛博朋克层（2026-10-20，第二版，取代上面规则 1、4 里的色值）

**依据**：
- CD PROJEKT RED 的 Bogna Gawrońska 为《赛博朋克 2077》义体医生诊所画的两张灯光氛围图（[ArtStation](https://www.artstation.com/artwork/QrPNRE)，只作分析，没有用作贴图，也没有照搬造型）。
- ArtStation 上 2077 相关诊所条目的描述（[Mark Foreman](https://www.artstation.com/artwork/48qLnl)：冷色手术光配暖橙点缀；[Kuba Wichnowski](https://kubatuba.artstation.com/projects/28XY2a)：Victor 诊所）。

**从参考图里提炼的要点**：
- 底色是很深的蓝青色，黑色深、几乎没有中间灰；
- 手术区用冰冷的青白多头无影灯，地面有一圈亮的光池，四周挂半透明塑料帘；
- 旁边单独一个“热区”：橙红灯管、橙色屏幕；
- 到处都是小发光点：青色 UI 屏和全息面板、天花和设备上红黄指示灯点、玻璃柜青色边缘光；
- 地面暗但有一点反光。

**落地方式**：
1. **按区定色相，互不混色**：
   - 房间荧光灯：深蓝青（0.56, 0.84, 0.98）；
   - 手术台：冰白无影灯，是全场最亮的；
   - 交易柜台：橙红热区，上方吊两根橙红灯管，加一盏橙红点光；
   - 维修台：琥珀工作光；
   - 机器人维修座：服务青。
2. **霓虹点缀**：
   - 门上方粉品红“义体维修”，旁边青色“24H”；
   - 东南墙竖排橙色“收件处”；
   - 龙门环下方一圈青色霓虹，环外侧一圈琥珀和红色指示灯点。
3. **全息**：
   - 手术台头端的人体扫描面板、两侧的生命体征和总线图面板；
   - 维修台上方三块小屏；
   - 一道青色扫描光每 6 秒沿床身扫一遍。
4. **塑料条帘**：挂在龙门环外 1.13 m 处，高度 2.02–2.38 m，全部在头顶以上，没有碰撞体，不挡任何通道。
5. **湿地面**：地面材质用一份副本，光泽调到 0.62；加一个只渲染一次的反射探针，让霓虹在地上拉出反光。
6. **后期**：
   - 对比 +18、饱和 +6、色温 -8；
   - 辉光 0.65（阈值 0.85）；
   - 暗角 0.26，房间加一点色散（0.06）；
   - 维修近看保持清楚：对比 +6、辉光 0.3、不加色散。
7. **霓虹亮度**：HDR 倍数在 2.0–2.4 之间，灯管芯保持本色，靠辉光出光晕。倍数太高会把颜色烧成白色。
8. **不做的**：不用紫蓝色铺满整个房间（原参考交接文档的约束）；不用 2077 的标志、字体或店名。
