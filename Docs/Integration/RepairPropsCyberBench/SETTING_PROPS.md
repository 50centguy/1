# 道具与设定一致性（2026-10-20）

## 设定（从项目自己的资料整理，不是新写的）

- **地点**：北坡港务（NSP）边境港区的夜间维修铺，在地下。原创设定，见 `Docs/Narrative/WorkerHand_Slice.md`。
- **顾客**：港区装卸工罗亚、夜班管线巡检员、巡线员老周、货运司机阿坎、夜班护理员、街区照护站、回收站小梅、二手义体商、收藏家。都是夜班和底层工作者。
- **物件**：信号接收器、记忆卡匣、维修电源、赛博御守、通讯器、导航信标、回收无人机、工人义手、UNIT 07 维修机器人。
  - 技术水平是卡带 / 卡匣、接收器、CRT 屏一代的“卡带未来主义”。
  - 东西是租来的、修过的、捡来的。
- **制度与痕迹**：
  - 租赁义体贴着租赁方封条（“NSP PORT LEASED / VOID IF OPENED”）；
  - 边境导航设备的检修封签必须完整；
  - 顾客反复要求保留通话记录、录音、原身份和校准参数；
  - 房租 1200 第 3 晚到期，有付款压力。
- **美术交接里的原则**（`art-reference-handoff.md`）：
  - 赛博朋克感来自二手义体、混用品牌、补线、旧胶带、手写编号和过期耗材；
  - 画面不依赖全屏故障特效、强闪烁或扫描线；
  - 参考方向是 cassette futurism 医疗设备、复古工业诊断屏。

## 规则

1. **屏幕都是实体设备上的屏**：CRT、单色荧光屏、段码 LCD、指针表头、指示灯。不用悬浮全息。
2. **流程里出现的设备要在台上看得到**：
   - “外部测试连接 / 负载”和“测试供电”对应桌上的测试座：指针表、开关、香蕉插孔、夹线；
   - 卡匣“只读核对”对应读卡座；
   - 状态由维修流程驱动。
3. **工具是旧的、修过的、品牌混杂的**：缠胶带、手写编号、贴纸，其中有一件是港区租借物资。
4. **桌面上要有生活和制度的痕迹**：纸质工单夹、封签卷和检修章、房租催缴单、票据钉。
5. **霓虹只留在招牌上**，而且是旧的：脏灯箱、一笔坏掉在闪。

## 2026-10-20 墙面、柜台、维修座

- 维修台背墙：钢制洞洞板 + 工具影子板（空着的螺丝刀轮廓）、维修许可证、UNIT 07 蓝图、航运月历、待修工单；墙装绿色波形监视器移除（与桌面 CRT 重复）。

## 2026-10-21 规则调整：投影字、日文 / 英文标牌、人物

- 规则 1 的补充：**墙上的字改用投影**（用户要求）。投影来自实体设备：吸顶投影仪有机身、镜头和光束，字落在真实的表面上（招牌底板、挂起的投影幕、墙面、柜台裙板），不在空中漂浮。手术台周围仍然没有全息面板。
- 房间里的标牌用日文和英文（"義体修理"、"受付窓口"、"料金表 // PRICE LIST"、"作業台 // WORKBENCH"）。工单、账本、顾客对话、界面仍然是中文。
- 储物家具也要符合设定：二手、标签手写或印刷、看得出用途（零件抽屉墙、生体部品冷藏柜、二手义肢架、员工储物柜、港务运输箱），不用纯色方块。
- 人物：港区的夜班劳动者和街区上的人，低多边形日系画风，和道具一样有使用痕迹（护士的义肢前臂、巡检员的反光背心和安全帽、义体商的义眼和工装大衣、房东的烟）。
