## 2. 怎么选出来的（`sweep.md`、`fiber_variants.md`）

**积尘颜色**：试了 7 种底色（D0 原色、D1 略暗灰褐、D2 暗灰褐、D4 很暗的褐、D5 浅冷灰、D6 中等灰褐、D7 暖褐），在 cam2、玩家站位、总览、近看四个镜头下比较堵塞 / 清理两帧。

- 单纯压暗（D2、D4）几乎不增加“变化像素”，因为能变的面积就是进气口那 ~1000 px；压太暗反而和护栅缝里的阴影混在一起。
- 冷灰（D5）比原色还差。
- 暖褐 D7 的平均色差最高（cam2 28.5、站位 28.1），色调和周围冷灰的上盖、黑色风道拉开。它偏黄不偏红，不会被当成故障高亮。

**纤维**：在编辑器里从导入网格生成 5 个试验变体（F0 原样、F1 减半、F2 加粗 1.4、F3 加粗 1.8、F4 减半 + 加粗 1.4），每种颜色都跑三种运动。

- 闪烁指标：每帧（游戏渲染 MSAA 1x + FXAA − 同帧 8× MSAA 参考）的误差图，在纤维像素上随时间的二阶差分。稳定的模糊不算，只算一帧一帧忽隐忽现的锯齿。
- 只加粗（F2、F3）：每个纤维像素的锯齿闪烁基本不降，覆盖面积还变大，总量变大。
- 减半（F1）：闪烁面积减半，总量减半，但察觉度略降。
- 减半 + 加粗 1.4（F4）：闪烁总量和 F1 一样低，察觉度补回来（D7 下 cam2 ΔE > 10 像素 963，原样 971）。选这个。
- Unity 试验变体 F4 是 1 854 三角；写回源脚本后，短纤维按各自的循环隔一取一，实际是 1 634 三角。最终对比用的是重建后的真实资源。
