# 七号故障美术 · 真实场景验收（布局 B 为主，A 同条件对照）

## 结论

- **红色故障高亮**：复核是关的。所有状态、所有渲染器都没有红色覆盖色。
- **保养标记过曝**：已修正。近景镜头 7 下，纸面从 0.89 降到 0.80，字和纸的亮度差从 0.12 升到 0.26，四行字都能读。但它**只在近景镜头可读**，常用镜头和玩家站位都读不了。
- **轴承区过暗**：真正暗的是工作台托盘 / 轴承盒一带，已修正。工作台镜头下旧件亮度 0.16 → 0.23，近景对比镜头 0.20 → 0.33。
  - 发动机里的轴承位原来不暗，但亮在默认天空反射（发蓝，地下诊所里不合理）。改成房间反射后更暗一点、更真实：0.43 → 0.39。
- **能否凭外观区分**：

| 区分什么 | 常用镜头 | 近景镜头 |
|---|---|---|
| 堵塞 / 清理后的进气口 | 左引擎镜头 2 和玩家站位下能看出，要留意 | 9 明显 |
| 磨损 / 新轴承（在轴承位上） | 只有很小一块 | 只在 9 可读 |
| 旧件 / 新件（在工作台上） | 工作台镜头 4 和站位下，色调差能看出（旧件偏褐、更斑驳） | 锈斑和碎屑只在 8 可读 |

- **细纤维闪烁**：存在。在纤维覆盖的像素上，运动时闪烁是去掉纤维时的 1.8–4.3 倍；但纤维只占进气口画面的 0.4–6%。
  - 已打开 FXAA，降到 1.3–3.0 倍。
  - 剩下的闪烁来自纤维太细，不是面数多。**低面数版解决不了，也不需要**：故障美术件在这台机器上渲染开销在噪声范围内。
- **验证范围**：**真人鼠标试玩没做**，留给你验收；本轮只用程序把流程推进到各个状态再拍图，不算点击验收。**VR 文字可读性、目标硬件性能均未验证。**

## 6. 细纤维运动闪烁

- **镜头运动**：用三种，每种都按 60 帧/秒逐帧渲染。
  1. 原型的镜头切换（维修座 → 左引擎，0.35 s）；
  2. 左引擎镜头绕进气口慢转 ±8°（模拟头部或自由视角）；
  3. 近看镜头慢推 10 cm。
- **指标**：只在“纤维像素”上算，即同一帧有纤维和去掉纤维差别明显的像素。算法是相邻三帧亮度的二阶差分。

**布局 B**（A 的结果几乎一样）：

| 运动 | 纤维占进气口画面 | 不抗锯齿（原设置） | FXAA（已采用） | SMAA 高 |
|---|---|---|---|---|
| 镜头切换 | 0.4% | 1.95× | **1.33×** | 1.54× |
| 绕进气口慢转 | 1.2% | 3.71× | **2.33×** | 3.00× |
| 近看慢推 | 4.2% | 4.28× | **2.95×** | 3.35× |

（倍数相对“去掉纤维”。）

**判断**：

- 纤维确实会闪：细于一个像素的几何在没抗锯齿时忽隐忽现。
- 但面积很小；常用的左引擎镜头下只是进气口中心几十个像素。
- FXAA 降了约三成，剩下的要靠美术处理纤维：做粗一点、少一点，或者远处淡出。
- 这不是面数问题，**低面数版解决不了闪烁**。
- 时间抗锯齿（TAA）需要连续帧，这套逐帧离屏渲染没法测，没有评估。
- 闪烁截帧见 `Crops/*_flicker_*`。**真人观感未验证。**

- **结论**：在这台机器上（RTX 3070，编辑器内），故障美术件带来的渲染耗时差别在 ±0.1 ms 以内，与测量噪声同级。

- **目标硬件性能未验证。**
