边境维修站 · 试玩说明与开发进度

项目概览

《地下义体维修处》（Border Repair Station） 是一个第一人称的赛博朋克维修店模拟游戏：玩家在边境港区的地下铺子上夜班，从柜台接活、在维修台上拆装维修、再交还给顾客，赚钱凑房租。整体美术方向是 PS2 时代的低分辨率、高对比观感。

项目说明
引擎Unity 6000.0.84f1，URP
平台Windows PC（Standalone x64）
美术风格低面数 + 全屏 PS2 后处理（448 虚拟扫描线、每通道 32 级量化、Bayer 抖动）
本次交付物BorderRepairClinic-Playtest-20261102.zip，Development 构建（含调试快捷键）
本包可玩范围第一晚完整流程（四单生意 + 打烊 + 维修机器人停靠）

本文档同时说明怎么玩和现在做到哪一步、还剩什么，后半部分是我接下来要做的工作清单。

怎么开始

  1. 解开 zip，保持文件夹完整，双击 BorderRepairClinic.exe。
  2. 游戏默认全屏，先出现开始页（标题「地下义体维修处」）。
  3. 选「开始营业」进入游戏。

几点正常现象：

  • 首次运行时 Windows 可能弹防火墙提示，点取消不影响游戏。
  • 这是 Development 构建，画面角落可能带开发信息，不用管。
  • 开始页期间，游戏内快捷键（F4、F5、F1、-、T、=）会被屏蔽，按了不会有副作用；按 Esc 也不会退出，要退出请选菜单里的「退出」。

一局怎么玩

进入游戏后，鼠标转头，屏幕中央的小点是准星。准星对着能操作的东西时会变绿并提示「左键：……」；变成琥珀色时，提示写的是现在不能操作的原因。伸手距离只有一米多，提示「够不着」就走近一点。

不知道下一步做什么时，按 F1，帮助页最上面一行「现在：……」会告诉你。

第一步：收件

走到交易区，收件台亮灯就表示有活。准星对准台上的物品，按左键接收，再点对话框的「继续」听完顾客的话。物品这时拿在你手上。

第二步：放到维修台

走到维修台（标着 WORKBENCH），准星对准台面，按左键放下。镜头切到台前，光标自动松开，可以开始修。

第三步：维修

用鼠标点右侧操作窗口里的按钮，或直接点物品上的部件。每一单的顺序大致相同：

  1. 初测：接上外部测试连接并通电，运行测试，看到症状。
  2. 拆解：断电、解除测试连接，然后开盖、拆线、拆模块。
  3. 更换或修理：把坏的部分处理掉。
  4. 复装：按相反顺序装回去。
  5. 复测：重新通电测试，通过后在「整件」里确认交付。

拧螺丝、撬盖板、拔插头这类动作要亲手做，屏幕会提示怎么拖鼠标；按 Esc 可以取消当前动作。右键拖动转物品，滚轮缩放。

换件要先买配件。 提示缺配件时，点屏幕左上的 SYS 图标 →「01 配件采购」。物品在维修台上时，采购窗口会标出「▶ 本单兼容」的那一件。加入数量后确认采购即可，开店现金 500 够用；多买的可以在「库存」页退回。

中途想走开，点左上角的「离开维修台」；要回来就点「回到维修台」，或者走过去左键点台上的物品。

第四步：交货

确认交付后，你会回到房间，物品出现在交件台上，交件台的灯在闪。走过去，准星对准后按左键交付，钱这时才入账。然后收件台会亮灯，回到第一步接下一单。

第五步：打烊

四单都交付后，账本会自动弹出。看完点「确认账本，打烊」。

第六步：让七号停靠

先是一段自动演出：七号端着零件盘飘着，机身慢慢倾斜。等它播完，不需要操作。

然后按屏幕上的「下一步」提示，亲手完成停靠：

  1. 点维修座夹具的黄色握把，夹具张开，七号落座。
  2. 等它坐稳，再点一次握把，夹紧。
  3. 点断电开关，拨到 OFF。
  4. 等涡轮停转，屏幕下方出现「登记内部维修单（今晚不拆）」，点它。

准星不好对时，按 1 切到维修座的固定机位，直接用鼠标点，也不受距离限制；按移动键回到行走。

第七步：结束面板

面板会显示现金、还差多少房租，以及存档结果。到这里第一晚就结束了，点「退出游戏」离开。

特色系统：污渍清除

这是本作区别于普通维修模拟的地方：物品外壳上的油污、积灰、锈迹是可以亲手擦掉的，而且和维修流程完全解耦——不做也能通关，做了会看到外壳真的变干净。

  • 怎么进入： 物品在维修台上时按 C（或点左下角的「清洁工具」）。只有在物品还没修完的检查阶段才能用。
  • 怎么擦： 按住左键擦，右键转动物品，滚轮缩放。再按一次 C 放下工具。
  • 能擦的： 物品外壳上的污渍。
  • 不能擦的： 屏幕、标签和封条，这些要保留。擦到时会提示「这里不能擦」。
  • 笔刷圈的颜色： 绿色表示能擦，琥珀色表示不能擦，淡白色表示已经干净。
  • 进度和完成： 左下角显示「污垢清除 N%」和进度条。擦到接近干净时，剩下的零星污点会一次收尾，然后响起完成音，出现「清洁完成」。

四个物品的脏法各不相同：接收器是油腻的指纹印，卡匣是抽屉里落下的细灰，电源是烟灰色的大块污迹，御守是浅浅的绒屑和手油。污渍按物体空间生成，跨 UV 缝连续，不会因为贴图拼接而出现接缝。

场景里也有故事性的污渍：地板上有被人走出来的抛光路线（从门口到柜台、柜台到工作台、工作台到维修坞），工作台上有干掉的助焊剂残迹。维修机器人七号身上的油垢是布景，擦不掉。

试玩快捷键

这一版是 Development 构建，所以下面这些键可用：

按键作用
F4立刻清除当前维修物品上的污渍
F5快捷完成当前一步；做不了时会说明原因

F5 有两处跳不过去：买配件（要自己去 SYS 菜单买）和七号停靠（必须手动操作）。

这一版没有的东西

  • 第二晚和七号维修：只能玩到第一晚结束。
  • 主菜单和读档：包里没有这些场景，所以相关入口已经隐藏——结束面板上没有「回到主菜单」，SYS 菜单里只剩「01 配件采购」。
  • 中途退出入口：要退出请按 Alt + F4。第一晚结束面板上的「退出游戏」可以用。

已经验证到什么程度

已验证：

  • 构建成功，0 error；启动后标题页正常显示，连续运行 30 秒不崩溃。
  • 玩家运行日志里没有异常（没接 VR 头显时会有 OpenXR 报错，不影响游玩）。
  • 中文字体与画面用到的自定义 shader 都在包内。
  • 自动化测试：EditMode 277 项（通过 268、失败 9，失败项均为既有问题）；PlayMode 201 项（通过 192、失败 1、跳过 8，跳过的都是标记为 Explicit 的截图测试）。详见下面的「工程债」一节。
  • 清洁玩法的四条音效触发、笔刷手感参数、污渍遮挡判断、开始页关闭后的状态交接，都有对应测试覆盖。

已知问题

  • 存档可能覆盖别的包： 存档位置和其它同名试玩包共用，打完第一晚会覆盖原有的检查点：%USERPROFILE%\AppData\LocalLow\DefaultCompany\BorderRepairStation\TwoNightSlice\checkpoint.json
  • 个别视角擦不到东西： 用滚轮把镜头拉近再试。
  • 固定机位键位描述不一致： 代码实际接受 1–9，帮助页只写了 1–4，5–9 也能切机位。

我接下来还要做的

一、影响能否完整试玩的（优先）

  1. 把第二晚接上。 现在第二晚的场景、主菜单和读档流程都没有打进包，所以只能玩到第一晚结束。需要把主菜单场景加入构建、把「继续」的读档路径验证通，或者改成在同一场景内推进到第二晚。
  2. 存档按构建版本隔离。 目前所有同名包共用一个检查点路径，我自己的几个测试包会互相覆盖。

二、玩法与内容

  1. 剧情重写。 现在的顾客台词、故障来由和夜班流程是第一版，需要整体重写过一遍：四个单子的因果、房东压力这条线、以及七号和助手在其中的位置，都要重新串一遍。
  2. 给每件物品配一份说明书。 目前故障和拆装步骤基本靠界面上的操作提示在带；要给四件维修物各写一份能在游戏里翻阅的维修说明书——结构图、接线、拆装顺序、哪些是保留件——让它成为独立于操作提示的一条信息来源。
  3. 硬核模式：把提示全撤掉，让玩家照着说明书自己摸。 现在「现在做什么」的提示、准星提示和 F1 帮助页承担了大部分教学；硬核模式下这些都不给，只留说明书和故障现象，玩家得自己判断从哪下手、该测什么、哪些部件不能动。这一条依赖上一条，说明书没做出来之前这个模式没法玩。
  4. 开场引导。 目前只有 F1 帮助页和屏幕上的准星提示，缺少主动教学——试玩者的第一反应普遍是「不知道该做什么」。
  5. 手术与近景流程的引导。 叫病人进来后的一系列动作（解束带、扣束带、对准右前臂进入近景）提示还不够明确。
  6. 房间级的故事污渍还没铺满。 地板的人流路线和工作台的助焊剂残迹已经做了，墙面渗漏痕、墙脚积灰这类更细的表面还没做。
  7. 七号的油垢需要重做。 现在是均匀分布的油污，不是从一个具体漏点淌出来的，故事感不足。

三、美术与表现

  1. 人物模型重制。 顾客、助手、病人这批人物模型要重做一遍——统一到同一个低多边形 PS2 口径上，同时让脸和体型的辨识度够，玩家在柜台和手术台前能一眼分清是谁。
  2. 全息投影的可读性。 之前给全息招牌加过一层图形动效，结果反而降低了文字可读性，这部分已经搁置，需要重新找方向。
  3. 地面与墙面的贴图重做。 计划是把锈迹做得更小、更去饱和，并补上法线贴图；目前贴图的高频细节靠 shader 补，还缺真正的起伏。
  4. 整体亮度偏低。 房间在夜戏里偏暗，需要再调一轮曝光与灯光分布。
  5. 音效统一。 清洁的四条音效（擦、刮、扫、完成）已经接好，其余维修动作与环境音还没有整体过一遍。

四、工程债

  1. 既有测试失败。 EditMode 有 9 项失败，集中在 FirstOrderSceneTests（场景几何悬空、源 FBX 哈希与记录不符），是本轮之前就存在的；PlayMode 有 1 项顺序相关的失败（单独跑能过、整套跑会挂），尚未定位。
  2. 性能没有任何基线。 现有性能测试只断言三角面数大于 0，判断不了预算；而且它统计的是 Renderer，数不到污渍层这种用 Graphics.DrawMesh 画的几何。需要补一次真实的帧时间与显存测量。
  3. 构建报告缺明细。 打包只记录了 warning 的数量（这次是 3 条），没有内容，分发前得人工确认。
  4. 细节不一致。 固定机位键位 1–4 与 1–9 的描述不一致；助手开场的招呼语没有做开始页屏蔽，可能被标题页吃掉。
