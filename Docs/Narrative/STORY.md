# 边境维修站 · 完整剧情与设定文档

2026-11-18 修订版。用于对齐游戏剧本、JSON 台词重写以及大学院研究计划书的核心设定。

**本文件是剧情的权威来源。** 改 JSON 台词、做第二晚、第三晚，都以这里为准。第一到第六节是定稿正文；第七节是和现有工程的对应、还没解决的小问题。

## 一、核心主题与舞台定位

### 核心主题

**人不是零件。** 在一个把身体和劳动都当成“可替换耗材”的时代，通过“修（保留原物与痕迹）”**而不是**“换（清零替换）”，去决定一个人的存在是该被抹掉，还是被留下来。

- **玩法映射**：几乎每一单都存在“省事/直接换新或格式化”与“费劲/花钱保留旧件或个人印记”两种做法。系统不评判对错，只结算金钱、时间与风险。
- **核心规矩**：`只核对身份，不打开私人记录`（主角义眼固件的底层只读限制）。玩家永远知道得比物主少，靠部件上的物理痕迹与元数据拼出隐情。

### 舞台与世界观

- **舞台**：大厂搬离、官方售后撤走后的衰退老工业港区。地下室一间只开夜班的个体维修铺，门口投影招牌写着 `義体修理 / CYBERWARE REPAIR · 24H 営業中`，下面贴着手写纸条：`只接夜班 · 概不赊账`。
- **定位区分**：不是赛博朋克常见的“街头黑诊所”，而是**既修旧对讲机、老电源，也兼修老式重型工业义体**的街区杂项维修铺。大厂眼里义体是耗材，但对留在这片区的人来说，用过十一年的机械手和哥哥留下的旧对讲机一样，都是舍不得扔的旧物件。
- **监管与封条**：制造厂商虽已撤离，但港区的设备安全巡查（安全监管处）仍在运转，专门抽查地下铺子是否私自拆封、违规改装无证黑机。
- **经济目标**：三晚打烊前凑够 **1200** 房租（开店现金 500，第一晚结束账上 800，还差 400）。

## 三、开场设计（约 10 秒进可操作状态）

不写背景介绍旁白，用**环境声景 + 义眼冷启动**直接把人带进地下室：

1. **黑屏入声（0–3 秒）**：远处码头一声沉闷的汽笛，接着老式电梯剪刀铁门“哗啦”拉开的金属摩擦声，地下室荧光灯“滋啦”通电。
2. **义眼冷启动 UI（3–7 秒）**：黑屏上逐行跳出低分辨率琥珀色自检文字：

   ```
   OCULAR_OS v2.4 // REBOOTING...
   OPTIC LINK .......... OK
   COMM MODULE ......... OK
   PRIVACY LOCK ........ READ-ONLY (NO LOG PLAYBACK)
   ```
3. **画面展开与常驻 HUD（7–10 秒）**：画面像老 CRT 电视从中间“啪”地展开，站在刚拉开铁门的门口，投影招牌亮起。视野角落固定两个极简提示：右上 `NIGHT 01 // 22:00`，左下 `RENT DUE: 1200 (BY NIGHT 3)`。桌面左上贴着黄色便签 `RENT DUE 1200 BY NIGHT 3`，压着 500 现金。
4. **开机与弹窗来电**：玩家走过去打开**七号**电源，七号浮起亮出笑脸；紧接着视野右上角闪出义眼来电弹窗 `INCOMING CALL：ミヨコ（美代子）`，直接进耳麦接听 14 秒催租电话。挂断后，门外**小遥**推门进来交第一单。

## 四、三晚完整剧情与台词草稿

每单统一采用“接单（3 句内）→ 拆修与痕迹发现（无声）→ 手艺选择（用动作表态）→ 交件收尾（停在具体动作）”的四步结构。

### 第一晚 · 开张（账上 500 → 800，还差 400）

1. **开门与催租**
   - **七号**：“晚上好，老板。UNIT-07 通电正常。今天也是搬货我来，动手你来。”
   - **美代子**（义眼弹窗来电，打火机声）：“喂？是我，美代子。提醒你一声，第三晚打烊前一千二放桌上。少一个子儿我直接把你门口那破招牌摘了。……底下潮，别通宵硬扛。挂了。”
   - **七号**：“房东小姐的通话时长为 14 秒。另外，我身上的原厂合规防拆封条共七张，目前全部完好。”
2. **第 1 单：小遥的对讲机（教学）**
   - **接单**：小遥摘下对讲机放上柜台，安全帽没摘：“……开不了机。进水了。两点前能修好吗。”主角：“先拆了看。加急的话多算五十。”小遥：“行。弄好打我终端。”
   - **痕迹**：后盖内侧油性笔写着 `12-B`；电池仓贴着胶布 `哥 02:10 别关`；主板边缘一圈白色海盐结晶。
   - **手艺选择**：【换整套新模组和外壳（省事）】 / 【只换射频小板，洗掉盐渍并保留带字后盖与旧胶布（费时）】。
   - **回电**：小遥：“……试过了。底噪没了。刚才两点十分，频段里跳出一个信号，呼号还是 12-B。”主角可选【告诉她上面换了自动巡检，沿用了旧呼号】或【沉默，只说机器修好了】。若告诉她，小遥停两秒：“……嗯，我知道不是他。钱转过去了。两点十分，我再去那边走一趟。”（直接挂断）
3. **第 2、3 单：真由美的夜间电源 + 电子御守**
   - **接单**：真由美抱着两个盒子：“那个，老板，真不好意思这么晚跑来……照护站的夜间电源老跳闸，还有这个电子御守，按了没声音。能一起看看吗？老人家今晚等着呢。”
   - **痕迹（电源）**：线束上多焊了一根细线，胶布写着 `小绿·别拔`，主模块过载发黄。**手艺选择**：【剪掉多余私接线直接换主模块（快）】 / 【保留私接线，换高负载模块同时带动小绿（多花材料费）】。
   - **痕迹（御守）**：按键触点磨平。义眼只读核对身份时跳出元数据：`最近 212 条“晚安”录入源：照护站 03 号夜班终端`。
   - **回电**：真由美：“谢谢老板！刚试了，走廊灯和透析机都没跳……”主角可选【问她那两百多条“晚安”是不是她值夜班录的】或【不拆穿】。若被问到，真由美顿一下：“……你看出来啦。那孩子号码早停了，可三床奶奶每天睡前都要按一下。我总不能让它一直吱吱响吧。……谢谢你没拆穿，工钱我转过去了。”
4. **Frankie 来电 & 森田大叔露面**
   - **Frankie**（来电）：“Yo，听说岸壁底下新开了家修义体的？我是 Frankie，街口收废铁的。缺零件直接在终端找我下单，现结。货哪拆的别问，问就是海里捞的。……哦，要是客人叮嘱留旧件，你自己看着办，别砸我招牌就行。”
   - **七号**：“检索完成。Frankie 先生的库存清单里，有 42% 的零件登记在已倒闭厂商的报废表上。”
   - **森田大叔**（快打烊时推门）：“老板，关门了吗？……没大事，就这只老手，这两天干活老自己攥紧，掰都掰不开。你帮我用终端扫一眼？”
   - **柜台快扫**：老厂已停服，限力保护开关被人为旁路。**手艺选择**：【把限力调回安全值（干活会变慢）】 / 【听他的先不动，只清灰】。森田：“没事，别给我调小了，明天吊机班长又要骂人。先这样，能凑合干完这几天就行。谢了啊。”
5. **打烊伏笔**
   - **七号**（单手端盘向左倾斜 4 度，屏幕跳出 `TRAY UNSTABLE` 后稳住）：“……左引擎温度偏高 3 度。还在允许范围内。老板，去记账吧。今天账上 800，还差 400。”

### 第二晚 · 动刀

1. **开场来电**
   - **美代子**：“账我看了，还差四百。昨晚街口有安全巡查的人转悠，说你这儿可能有私改的黑机，我替你糊弄过去了。就这一次，别让我难做。明晚打烊前一千二，挂了。”
2. **森田大叔上手术台（23 步义体更换）**
   - **森田大叔**（右臂红灯锁死）：“老板，今天得真拆了。”
      - *第一晚调回限力*：“调完之后干活慢，班长今早直接把老子辞了。算了，本来也到年限了。”
      - *第一晚未调限力*：“今早吊机抓重箱的时候彻底卡死，老型号固件直接锁机了。组里换了全自动吊臂，我也该退了。”
   - **手术过程**：拧螺钉 → 拔电池服务插头断电 → 拔神经接头 → 切开 3 号螺栓上森田手写的医用胶布 `3号吊机·森田` → 卸下旧重手放上托盘 → 装上便宜的二手轻型手并联调握拳三次。
   - **交接**：森田活动新装的轻手：“轻得跟没长手一样。……旧的放这儿吧，签个字让回收船拉走。”随后终端弹出回收单，签收方 `岸壁潮汐回收船`，玩家签字收走旧臂。
3. **修七号（封条抉择）**
   - 七号断电停在维修座，左引擎锁扣压着原厂合规封条 `VOID IF OPENED`（禁止私拆改装核心固件）。翻开上盖内侧，保养记录写着 `前租赁：三号管廊巡检组`，轴承缝里卡着与第一晚对讲机相同的白色海盐结晶（不点破）。
   - **手艺选择**：
      - **自己撕封条硬修**：只花轴承钱，拆开后可顺手破解被原厂锁死的“维修协助模块”，第三晚七号升级为能递工具、提示故障步骤的真助手；代价是变成违规改装黑机，第三晚遭安全巡查核查。
      - **走终端报合规返修**：封条完整，但扣除一笔停用代检费，且第三晚七号处于停机送检状态，无法当助手。
   - **若自己修好**：七号浮起亮笑脸：“左引擎轴承已更换，辅助模块已解除锁定。老板，以后工具我来递。”
4. **夜末插曲**
   - **小遥**（*仅第一晚未告知时来电*）：“……昨晚两点十分，我自己听到了。是新机器吧。没事，跟你说一声。挂了。”
   - **七号**：“刚刚扫到照护站频段。型号为‘小绿’的旧看护机刚刚发了一次心跳包，运行正常。”

### 第三晚 · 算账（1200 房租到期）

1. **开场与公告**
   - **美代子**：“今晚到期，十二点前把钱放柜台。”
   - *（若第二晚撕了封条）*：终端弹出安全巡查处的红色通知 `UNIT-07 封条异常（疑似违规改装黑机），今晚 24:00 前缴纳罚金或上缴设备`，美代子随后再来电：“我昨天才替你挡过一次，你当耳旁风是吧？这次巡查再找上来我可不管了，自己兜着。”
   - **终端公告**：`三号管廊旧巡检呼号 12-B 将于今日 18:00 正式注销，替换为全自动编号。`
2. **小遥的最后来电**
   - **小遥**：“……看到公告了。今天起没有 12-B 了。”主角：“嗯。”小遥：“以后两点十分大概只有杂音了。不过我今晚还是会过去走一趟。……走了。”（挂断）
3. **森田的卡匣回来（核心抉择）**
   - **Frankie**（拎铁盒上门，绝口不提森田）：“老兄，大单子来了。刚从岸壁那条潮汐回收船上淘到个老式重型吊机义手的记忆卡匣，接口被谁拿铁片硬撬坏了，给修一下。”
   - **痕迹**：外壳刻着 `K.MORITA`，排线上缠着一圈与第二晚同款的医用胶布，写着 `别格式化`。玩家自己认出这就是昨晚签字送走的那条前臂里的卡匣。
   - **Frankie 报价**：“十一年吊机的老参数了，手感比新固件稳得多，新手装上就能直接上机。把里面那个旧属主区格式化抹干净，干净的手感才好卖。你只要点一下格式化，**我出双倍工钱**。”
   - **最终选择**（经济卡点：前两晚坚持留旧件、不省事的玩家，到此账上通常正好差这一倍工钱才够 1200）：
      - **保留 `K.MORITA` 名字**：只拿普通修机费。Frankie 吹口哨：“行啊，比我还轴。昨天我去回收船挑货，有个独臂老头顺着清运单一路追到泊位上，就为了缠这圈破胶布。……算了，看在你面子上，一会儿我把买家的电话推给他，让他们自己谈价去。”
      - **格式化抹掉名字**：拿双倍工钱凑租。Frankie：“聪明人。钱转你账上了，以后有这种干净货还找你。”（挂断）
   - **七号**（在 Frankie 走后）：“老式重型义手已经全部淘汰。……老板，要是哪天我也到报废年限了，会不会也有人把我的操作记录拆下来卖？……开玩笑的。先把今天账结了吧。”

## 六、台词与 JSON 编写铁律（去 AI 味对照）

1. **绝不替玩家总结主题**：角色嘴里不许出现“替身”“活过的时间”“人不是零件”之类论文金句。
2. **情绪藏在动作和停顿里**：多用具体零件名、时间点、金额数字收尾（例如“两点十分我再去走一趟”），不写排比句，不强行煽情。
3. **只写修理工看得见的东西**：所有隐情只通过物理磨损、胶布字迹、只读元数据和当事人只言片语拼出来，绝不让 NPC 替玩家点破。
