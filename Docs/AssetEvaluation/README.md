# AI 资产采用判断记录

本目录记录**开发阶段**对 AI 生成资产（或其他外部资产）的采用判断，属于开发流程文档。

- 它和游戏内的“维修判断”（`Assets/BorderRepair/Data/Cases/*.asset`）是两套独立的数据，互不引用。
- 不要把本目录放进 `Assets/`，也不要让游戏代码读取这里的文件。
- 只记录真实发生的评估；没有做过的实验不要预填结果。

## 文件

| 文件 | 用途 |
| --- | --- |
| `AssetEvaluation_Template.md` | 单个资产的完整评价记录。每评估一个资产，复制一份，命名为 `YYYYMMDD_<资产名>.md` |
| `AssetEvaluation_Log.csv` | 汇总表，每个资产一行，方便筛选和统计。表头与模板字段一一对应 |
| `Screenshots/` | 问题截图。按 `<记录文件名>_<序号>.png` 命名，在记录中写相对路径 |

## 判定取值

- **采用**：可以直接替换占位资产，无需修改。
- **返修**：方向可用，但需要修改后才能使用。必须填写返修时间、步骤和返修后结果。
- **放弃**：不满足条件，或返修成本高于重做成本。
